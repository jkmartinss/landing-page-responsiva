# Landing Page Responsiva

Landing page moderna e responsiva desenvolvida para praticar HTML e CSS, com foco em layout adaptável para diferentes dispositivos.

## Tecnologias
- HTML5
- CSS3
- Responsividade (media queries)

## Responsividade
- Mobile
- Tablet
- Desktop

## Funcionalidades
- Layout adaptável
- Seções organizadas (header, hero, conteúdo, footer)
- Design limpo e moderno

## Aprendizados
Neste projeto pratiquei:
- Estruturação semântica com HTML
- Responsividade com CSS
- Organização de layout
